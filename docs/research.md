# Research

## Problem

Node operators adding RPC endpoints ask: "Is it worth running an RPC? Will I profit or lose?"

## Approach

- Cost calculator (VPS + bandwidth + other).
- Real measurement (latency, success rate, availability) against a configured endpoint.
- Break-even analysis + profitability report with evidence.

## Data sources

- User-provided cost inputs.
- Measured samples from a user-configured, verified endpoint.
- No invented endpoints or methods.

## Status

Prototype (MVP).
